# 『이 책은 생존가이드가 아닙니다』

빚에 쪼들리던 헌책방 청년이 죽은 손님이 남긴 고대어 책을 '생존 지침서'로 오역해 3전짜리 팸플릿 『생존가이드』로 팔기 시작한다. 정말로 사람들이 살아남는다. 하지만 그 책은 100년 전 불태워진 마녀를 되살리는 마녀교의 금서였다.

- 장르: 다크 판타지 · 생존 · 미스터리
- 톤: 진지 + 코믹
