# 버츄얼 팬덤 타이쿤

버츄얼 스트리머 콘셉트의 브라우저 방치형 타이쿤. **내 응원 룸에서 최애를 응원해 재화를 벌고,
그 재화로 캐릭터 주식에 투자하거나 경매로 캐릭터를 사고파는** 게임입니다.

서버 없이 브라우저만으로 돌아가고, 진행 상황은 localStorage에 저장됩니다.
경쟁 입찰자와 시장 참여자는 시뮬레이션된 NPC(팬덤·투자자)로 구현되어 있습니다.

## 게임 루프

1. **응원 룸** — 응원석에 앉은 캐릭터 카드를 누르면 응원. 코인이 즉시 들어오고 인기도가 오릅니다.
   빠르게 연타하면 **콤보**가 붙어 최대 ×3까지 배수가 올라갑니다(자동 응원에는 붙지 않습니다).
2. **캐릭터** — 내 최애를 이름·소속·이미지로 직접 업로드. 등록하는 순간 주식시장에도 상장됩니다.
   (이미지는 320×320으로 리사이즈되어 이 브라우저에만 저장되며 어디에도 전송되지 않습니다)
3. **주식** — 캐릭터마다 주식이 있고 주가는 **인기도**를 따라갑니다. 90초마다 배당금이 들어옵니다.
4. **경매장** — 100초마다 새 매물이 등장. NPC 입찰자와 경쟁해 낙찰받거나, 내 캐릭터를 출품해
   낙찰금을 정산받습니다(수수료 5%). 밀리면 묶였던 입찰금은 자동 반환됩니다.
5. **상점** — 응원 위력, 자동 응원 봇, 응원석 증설, 오프라인 효율, 배당 배수를 강화합니다.

접속하지 않은 동안에도 초당 수입의 일부(기본 35%, 팬카페 업그레이드로 최대 90%)가
최대 8시간까지 쌓입니다.

## 캐릭터 성격

모든 캐릭터는 **성격** 하나를 갖고, 그게 수입·인기도 유지력·주가 변동성·배당·감정가에
서로 다르게 작용합니다. 그래서 "응원석에 앉힐 캐릭터"와 "주식을 살 캐릭터", "경매에서
돈을 쓸 캐릭터"가 서로 다른 판단이 됩니다.

| 성격 | 효과 |
|---|---|
| 🎮 게임형 | 수입 +30% |
| 🎤 아이돌형 | 인기도 상승 +45%, 수입 -10% |
| 🌙 힐링형 | 인기도 감소 -60% (팬이 잘 안 떠남) |
| 🔥 밈형 | 변동성 ×2.2, 감정가 -10% |
| 💎 굿즈형 | 배당 +55% |
| 🌱 신인형 | 인기도 상승 +70%, 수입 -20% |
| 🎖 베테랑 | 변동성 -45%, 배당 +20% |
| 👑 레전드 (희귀) | 수입 +25%, 감정가 +45%, 배당 +25% |

업로드한 캐릭터의 성격은 무작위로 정해집니다. 성격 수치는 `src/game/traits.ts`에 모여 있습니다.

## 도전 과제와 명성

14개의 도전 과제를 달성하면 코인과 **명성**을 받습니다. 명성 1점당 전체 수입이 영구히 +3%
올라가서, 장기 진행의 축이 됩니다. (상점 탭에서 진행률 확인)

## 기술 스택

- **언어**: TypeScript (프레임워크 없음, 의존성 0개)
- **빌드**: Vite / **린트·포맷**: Biome / **패키지 매니저**: pnpm
- 렌더링은 문자열 → `innerHTML` 방식이며, 포커스·캐럿·스크롤을 보존하는 `paint()`로 교체합니다.
  입력이 들어가는 모달은 실시간 수치에 의존하지 않는 별도 컨테이너에서 그려, 타이핑(한글 조합) 중
  다시 그려지지 않게 했습니다.

## 시작하기

```bash
pnpm install
pnpm dev      # 개발 서버
pnpm build    # 타입 검사 + 프로덕션 빌드 (dist/)
pnpm preview  # 빌드 결과 미리보기
pnpm lint     # Biome 검사
```

## 구조

```
src/
  core/      포맷터, 시드 난수, 타입 정의
  game/      게임 규칙 — 경제, 시장, 경매, 세이브, 루프(engine)
  ui/        렌더링 — 셸/이벤트(app), 뷰(views), DOM 유틸(dom)
```

밸런스 수치는 `src/game/balance.ts` 한 곳에 모여 있습니다.

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다
(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 동작합니다).
`vite.config.ts`의 `base: "./"` 덕분에 하위 경로나 itch.io 업로드에서도 그대로 동작합니다.
