# 버츄얼 팬덤 타이쿤

버츄얼 스트리머 콘셉트의 브라우저 방치형 타이쿤. **내 응원 룸에서 최애를 응원해 팬심을 쌓고,
그 인기로 굿즈를 팔아 번 돈을 주식과 경매로 굴리는** 게임입니다.

재화가 둘로 나뉘어 있습니다.

| 재화 | 무엇인가 | 어디에 쓰나 |
|---|---|---|
| 💜 **팬심** | 이번 시즌의 성적표. 응원할 때만 쌓인다 | **쓰이지 않는다.** 트로피 등급을 정한다 |
| 💰 **원** | 지갑. 시즌 시작에 **100만원**을 받는다 | 업그레이드·주식·경매 |

돈을 아무리 벌어도 팬심은 오르지 않고, 반대로 팬심을 쌓아도 지갑은 그대로입니다.
그래서 "트로피를 노릴 것인가, 자산을 불릴 것인가"가 실제로 갈리는 판단이 됩니다.

**응원은 돈을 만들지 않습니다.** 응원이 인기도를 올리고, 그 인기도를 **굿즈**가 원으로
바꿔줍니다. 굿즈 라인을 하나도 열지 않으면 수입은 0입니다.

```
응원 ──> 💜 팬심 ──> 🏆 트로피
  └───> 🔥 인기도 ──> 🏭 굿즈 ──> 💰 원 ──> 업그레이드 · 📈 주식 · 🔨 경매
```

서버 없이 브라우저만으로 돌아가고, 진행 상황은 localStorage에 저장됩니다.
경쟁 입찰자와 시장 참여자는 시뮬레이션된 NPC(팬덤·투자자)로 구현되어 있습니다.

## 게임 루프

1. **응원 룸** — 응원석에 앉힌 캐릭터를 **자동으로** 응원합니다. 페이지를 켜두기만 하면
   팬심이 쌓이고 인기도가 오릅니다. 연타할 것도, 누를 것도 없습니다.
   인기도가 높은 캐릭터를 응원할수록 한 번의 응원이 주는 팬심이 큽니다
   (`팬심 = 응원 횟수 × (1 + 인기도 × 0.02)`).
2. **캐릭터** — 내 최애를 이름·소속·이미지로 직접 업로드. 등록하는 순간 주식시장에도 상장됩니다.
   (이미지는 320×320으로 리사이즈되어 이 브라우저에만 저장되며 어디에도 전송되지 않습니다)
3. **굿즈** — 돈이 들어오는 유일한 상시 경로입니다. 캐릭터 한 명당 라인 하나(최대 8개).
   라인은 열어두기만 해도 **상시로** 조금씩 팔리고, **키트**로 한정판을 찍으면 재고가
   빠지는 동안 매출이 크게 뜁니다.

   **키트 등급** — 위로 갈수록 적게 찍습니다. 값을 만드는 건 성능이 아니라 **희소성**이에요.
   해금 조건은 이번 시즌 팬심인데, **팬심은 소비되지 않습니다** — 쓰는 게 아니라
   "살 자격"으로만 씁니다.

   | 키트 | 발행 수량 | 한 판이 가는 시간 | 매출 배수 | 해금 |
   |---|---|---|---|---|
   | 🥉 브론즈 | 500개 | 4시간 | ×0.6 | — |
   | 🥈 실버 | 200개 | 8시간 | ×0.9 | 팬심 1,500만 |
   | 🥇 골드 | 60개 | 16시간 | ×1.3 | 팬심 2억 |
   | 💎 한정판 | 12개 | 24시간 | ×1.8 | 팬심 12억 |

   **값은 내가 정하고, 한정 수량이 그 값을 검증합니다.** 적정가의 0.6~2.5배 중에서 고르면
   되는데, 비싸게 낼수록 덜 팔려서 오래 가고 완판 총액은 커집니다. 브론즈+키링 기준으로
   적정가는 6시간 40분에 2.53만원, 프리미엄은 24시간에 6.36만원이에요. 그래서
   **자주 들르는 사람은 싸게 빨리, 가끔 들르는 사람은 비싸게 오래**가 답이 됩니다.

   적정가로 완판하면 키트값의 **2.5배**가 돌아옵니다. 안 팔린 재고는 **원가의 40%**로
   떨이 처분할 수 있어서, 잘못 찍어도 손실이 제한됩니다.

   **종류**는 시간당 매출과 지속 시간을 맞바꿉니다. 상시 매출에는 영향이 없고 한정판에만
   걸려요.

   | 종류 | 매출 배수 | 판매 속도 | |
   |---|---|---|---|
   | 🔑 키링 | ×0.8 | 0.6배 | 한 판이 오래 간다. 방치할수록 유리 |
   | 🧊 아크릴 스탠드 | ×1.2 | 1.0배 | 무난한 기본형 |
   | 📖 화보집 | ×1.6 | 1.5배 | 매출이 크지만 금방 빠진다 |
   | 🧸 인형 | ×2.2 | 2.2배 | 폭발적. 자주 다시 찍어야 한다 |

   매출은 **그 캐릭터가 받는 응원 화력**에서 나오므로, 응원석에 앉혀 응원을 몰아줘야
   굿즈가 팔립니다. 자리에서 빼면 기본 판매력만 남고 인기도도 식어요.
4. **주식** — 캐릭터마다 주식이 있고 주가는 **인기도**를 따라갑니다. 90초마다 배당금이 들어옵니다.
   시장에는 항상 26명 안팎이 유지되며, 아무도 관심 없는 캐릭터는 경매가 끝날 때 정리됩니다.
5. **경매장** — 100초마다 새 매물이 등장. NPC 입찰자와 경쟁해 낙찰받거나, 내 캐릭터를 출품해
   낙찰금을 정산받습니다(수수료 5%). 밀리면 묶였던 입찰금은 자동 반환됩니다.
6. **상점** — 업그레이드는 주차별로 열립니다(아래 표). 시즌 시작 기준 경과 주차에 따라
   1주차 인프라 → 2주차 핵심 설비 → 3주차 최종 설비가 해금됩니다.

플레이어가 하는 일은 **누구를 응원석에 앉힐지**, **어떤 굿즈를 낼지**,
**번 돈을 업그레이드·주식·경매 중 어디에 쓸지**를 정하는 것뿐입니다.

## 한 달 진행 커브

한 시즌이 한 달이므로, 업그레이드가 한 달에 걸쳐 열리도록 주차별로 나눴습니다.
주차는 **시즌 시작 기준 경과 주**입니다(현재 local 모드에서는 가입 후 경과 주차).

| 주차 | 열리는 것 | 목표 |
|---|---|---|
| **1주차** | 🪑 응원석 증설 · 🔦 응원 화력 · ☕ 팬카페 운영 | 기초 인프라를 깐다 |
| **2주차** | 🤖 응원 속도 · 📣 홍보 대행사 · 📈 전속 증권사 | 핵심 설비 완성 |
| **3주차** | 🏛 팬덤 본부 · 🛰 글로벌 송출 · 🏭 굿즈 공장 | 최종 설비 완성 |
| **4주차** | (해금 없음) | 배당 ×1.5 · **주식과 경매로 자산 불리기** |

비용은 30일 시뮬레이션으로 맞췄습니다. 굿즈를 얼마나 챙기느냐로 갈립니다.

| 플레이 | 인프라 | 핵심 설비 | 최종 설비 | 시즌 팬심 | 트로피 |
|---|---|---|---|---|---|
| 재고 빠질 때마다 챙김 | 7일차 | 14일차 | **21일차** | 77억 | 👑 마스터 |
| 하루 한 번만 들름 | 8일차 | 15일차 | 시즌 막바지 | 56억 | 💎 다이아 |
| 굿즈를 아예 안 봄 | 14일차 | 19일차 | 미완성 | 40억 | 💎 다이아 |

**방치만으로도 다이아까지 갑니다.** 하루 한 번 프리미엄 가격으로 찍어두면 한 판이
24시간을 가니, 그 한 번의 탭이 격차의 대부분을 메웁니다. 마스터는 부지런히 찍어야 닿아요.

### 수입이 들어오는 규칙

| 상태 | 굿즈 매출·팬심 |
|---|---|
| 페이지를 켜둠 (탭이 뒤로 밀려도 동일) | **100%** |
| 페이지를 닫아둠 | 기본 35%, 팬카페 업그레이드로 최대 90% · 최대 8시간까지 |

닫아둔 동안에도 같은 효율로 팬심이 쌓입니다. 트로피 진행이 완전히 멈춰버리면
"켜두면 되는 게임"이 "24시간 켜둬야 하는 게임"이 되기 때문입니다.

## 시즌과 트로피

시즌 기준은 `src/core/season.ts`의 `SEASON_MODE` 한 줄로 정합니다.

| 모드 | 시즌 시작 | 길이 | 주차 기준 | 언제 쓰나 |
|---|---|---|---|---|
| **`"local"`** (현재) | 플레이를 시작한 시각 | 30일 | 가입 후 경과 주차 | 서버가 없어 모두가 같은 날 시작할 수 없는 지금 |
| `"calendar"` | KST 매달 1일 00:00 | 그 달의 일수(28~31일) | 달력 1일 기준 | 온라인 서비스로 돌릴 때 |

**온라인 전환은 `SEASON_MODE`를 `"calendar"`로 바꾸는 것으로 끝납니다.** 그때부터
시즌은 한국시간 매달 1일 00:00에 시작해 그 달 마지막 날까지 운영되고, 초기화는 무조건
1일 00:00입니다. 한국은 서머타임이 없어 UTC+9 고정으로 계산하므로 플레이어 기기의
시간대와 무관하게 전 세계가 같은 순간에 넘어갑니다. 기존 세이브는 다음 로드 때
자동으로 달력 시즌으로 옮겨갑니다(`applySeasonBounds`).

두 모드 모두 종료 판정은 `state.seasonEndsAt` 하나만 보므로 게임 로직은 동일합니다.

시즌의 성적표는 **그 시즌에 쌓은 팬심**이고, 그 수치로 트로피 등급이 정해집니다.
트로피가 이 게임의 최종 목표입니다. 주식·경매로 번 돈은 여기에 한 푼도 반영되지 않습니다.

| 등급 | 필요 팬심 | 명예 | 계속 켜뒀을 때 |
|---|---|---|---|
| 🥉 브론즈 | 200만 | +1 | 2일차 |
| 🥈 실버 | 1,500만 | +3 | 9일차 |
| 🥇 골드 | 2억 | +7 | 13일차 |
| 💠 플래티넘 | 12억 | +14 | 18일차 |
| 💎 다이아 | 32억 | +25 | 25일차 |
| 👑 마스터 | 68억 | +45 | 완주 + 한정판을 부지런히 |

날짜는 **하루 한 번 굿즈를 챙기는** 플레이 기준 시뮬레이션 결과입니다. 페이지를 닫아둔 동안에도
오프라인 효율만큼 팬심이 쌓이므로, 24시간 켜두지 않아도 진행됩니다.

팬심은 응원 횟수가 아니라 **응원 횟수 × 인기도**라서, 응원 속도(🤖)뿐 아니라 화력(🔦)·
홍보 대행사(📣)·글로벌 송출(🛰)·캐릭터 성격·응원석 배치가 전부 등급에 반영됩니다.
반대로 팬덤 본부(🏛)처럼 수입 배수만 올리는 설비는 지갑만 불리고 팬심은 건드리지 않습니다.

### 무엇이 초기화되고 무엇이 남는가

| 초기화 | 유지 |
|---|---|
| 원(다시 시드머니 100만원부터), 팬심, 업그레이드, 주식 포트폴리오 | 🏆 **트로피**(영구 기록) |
| 캐릭터 인기도·주가, 응원석 배치 | 🎀 **업로드한 캐릭터 보관함** |
| 도전 과제, 명성 | 명예 보너스(트로피 1점당 수입 +2%) |

보관함의 캐릭터는 새 시즌마다 이름·이미지·성격 그대로 다시 데뷔합니다. 트로피로 쌓은
명예 보너스는 다음 시즌 수입에 그대로 붙어서, 시즌을 거듭할수록 출발이 빨라집니다.

## 캐릭터 성격

모든 캐릭터는 **성격** 하나를 갖고, 그게 수입·인기도 유지력·주가 변동성·배당·감정가에
서로 다르게 작용합니다. 그래서 "응원석에 앉힐 캐릭터"와 "주식을 살 캐릭터", "경매에서
돈을 쓸 캐릭터"가 서로 다른 판단이 됩니다.

| 성격 | 효과 |
|---|---|
| 🎮 게임형 | 수입 +30% |
| 🎤 아이돌형 | 인기도 상승 +45%, 수입 -10% |
| 🌙 힐링형 | 인기도 감소 -60% (팬이 잘 안 떠남) |
| 🔥 밈형 | 변동성 ×2.2, 감정가 -10% |
| 💎 굿즈형 | 굿즈 매출 +55%, 배당 +55% |
| 🌱 신인형 | 인기도 상승 +70%, 수입 -20% |
| 🎖 베테랑 | 변동성 -45%, 배당 +20% |
| 👑 레전드 (희귀) | 수입 +25%, 감정가 +45%, 배당 +25% |

업로드한 캐릭터의 성격은 무작위로 정해집니다. 성격 수치는 `src/game/traits.ts`에 모여 있습니다.

## 도전 과제와 명성

16개의 도전 과제를 달성하면 상금(원)과 **명성**을 받습니다. 명성 1점당 그 시즌의 수입이 +3%
올라갑니다. (상점 탭에서 진행률 확인)

## 화면 테마

라이트(화이트톤)와 다크 두 벌을 지원하고, 헤더의 🌙/☀️ 버튼으로 전환합니다.

- 처음 열면 **기기의 시스템 설정**을 따릅니다(`prefers-color-scheme`).
- 버튼을 누르면 그 선택이 저장되어 시스템 설정보다 우선합니다. "처음부터 다시"로도 지워지지 않습니다.
- 색은 전부 CSS 토큰으로만 쓰고, 컴포넌트 규칙 안에서 색을 직접 쓰지 않습니다.
  한쪽 테마에서만 맞는 색이 박히는 걸 막기 위해서입니다. 트로피 등급색처럼 원본이
  고정된 색은 `color-mix`로 본문색과 섞어 두 테마 모두에서 읽히게 합니다.

## 기술 스택

- **언어**: TypeScript (프레임워크 없음, 의존성 0개)
- **빌드**: Vite / **린트·포맷**: Biome / **패키지 매니저**: pnpm
- 렌더링은 문자열 → `innerHTML` 방식이며, 포커스·캐럿·스크롤을 보존하는 `paint()`로 교체합니다.
  입력이 들어가는 모달은 실시간 수치에 의존하지 않는 별도 컨테이너에서 그려, 타이핑(한글 조합) 중
  다시 그려지지 않게 했습니다.

## 시작하기

```bash
pnpm install
pnpm dev      # 개발 서버
pnpm build    # 타입 검사 + 프로덕션 빌드 (dist/)
pnpm preview  # 빌드 결과 미리보기
pnpm lint     # Biome 검사
```

## 구조

```
src/
  core/      포맷터, 시드 난수, 타입 정의
  game/      게임 규칙 — 응원(economy), 굿즈(goods), 시장, 경매, 세이브, 루프(engine)
             room.ts에는 응원과 굿즈가 함께 쓰는 배수들이 모여 있다
  ui/        렌더링 — 셸/이벤트(app), 뷰(views), DOM 유틸(dom)
```

밸런스 수치는 `src/game/balance.ts` 한 곳에 모여 있습니다.

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다
(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 동작합니다).
`vite.config.ts`의 `base: "./"` 덕분에 하위 경로나 itch.io 업로드에서도 그대로 동작합니다.
