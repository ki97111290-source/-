# 치지직 버츄얼 방치형 RPG

치지직(CHZZK) 버츄얼 스트리머 콘셉트를 담은 방치형(Idle) RPG 게임 프로젝트입니다.

## 소개

캐릭터를 성장시키고 재화를 모아 방치 중에도 성장이 이어지는 인크리멘탈(incremental) 게임을 목표로 합니다. 베이스 템플릿으로 [crgeary/idle](https://github.com/crgeary/idle)의 TypeScript 스타터를 사용합니다.

## 기술 스택

- **언어**: TypeScript
- **빌드 도구**: Vite
- **린트/포맷**: Biome
- **패키지 매니저**: pnpm
- **런타임**: Node.js

## 시작하기

```bash
# 의존성 설치
pnpm install

# 개발 서버 실행
pnpm dev

# 빌드
pnpm build
```
