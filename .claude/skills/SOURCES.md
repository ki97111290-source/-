- 의존성(Python 패키지, npm, ffmpeg 외 도구)은 설치하지 않았다. 각 스킬을 처음 쓸 때 해당 SKILL.md의 설정 단계를 따른다.
- API 키가 필요한 스킬: video-use(ElevenLabs), pexo-agent, higgsfield-*, kling-ai*, claude-video-vision(Gemini/OpenAI 선택), video-producer-agent 등.
- 각 스킬의 라이선스는 원본 저장소를 따른다.
