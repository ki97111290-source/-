# 쇼츠: "은행 터는 법" (반전: 월급) — 설계

## 의도
진짜 범죄 다큐처럼 진지하게 끌고 가다가 마지막에 "월급"으로 반전하는 개그 쇼츠. 웃음 포인트는 진지함과 반전의 대비.

## 목표 / 비목표
- 목표: 세로 1080×1920, 약 30초, 첫 2초 안에 시선 잡기, 마지막 반전이 확실히 터지기.
- 비목표: 실사 영상, AI 생성 영상, 실제 범죄 방법 묘사(권총·위협은 아이콘 수준의 클리셰로만).
- 안티목표: 반전 전에 "월급"을 눈치채게 만드는 연출, 자막과 음성 불일치.

## 결정된 것 (사용자)
- 화면: 글자·그래픽 애니메이션 (A안)
- 음성: Microsoft 한국어 InJoon(남성), 다큐 톤, 속도 약 -10%, 톤 약간 낮게
- 대본: 사용자 대본 그대로, 조사 정도만 다듬기
- 장면 구성(7장면, 0~31초)과 톤(검은 배경·빨간 강조·타자기 자막, 반전에서 밝은 사무실 색)

## 방식 (검토한 안)
- A. 키네틱 타이포 + 아이콘 애니메이션 — **선택**. 여기서 바로 제작 가능, 비용 없음, 개그 타이밍 조절이 쉬움.
- B. AI 생성 영상 — API 키·비용 필요, 장면 품질 들쭉날쭉.
- C. 직접 촬영 영상 — 사용자 촬영 필요.

## 빌더에게 맡긴 것 (Claude 판단)
- 렌더러: HyperFrames(HTML→MP4). 실패 시 Remotion.
- 장면 길이는 실제 음성 길이에 맞춰 조정(위 표는 기준).
- 배경음·효과음은 ffmpeg로 직접 합성(저작권 없음).
- 한국어 폰트: Noto Sans KR (npm @fontsource).
- 아이콘은 이모지 대신 SVG 도형으로 그림(렌더 환경에 컬러 이모지 폰트 없음).
