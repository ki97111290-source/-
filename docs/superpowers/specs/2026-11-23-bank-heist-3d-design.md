# 쇼츠: "은행 터는 법" 3D 단면 애니메이션판 — 설계

## 의도
같은 대본(반전: 월급)을 3D 단면 디오라마 애니메이션 스타일로 다시 만든다. 사용자가 보여준 "땅굴" 쇼츠처럼 땅/건물을 잘라 속을 보여주고, 캐릭터가 움직이며, 화면 가운데에 한두 단어 자막이 크게 뜨는 형식.

## 결정된 것 (사용자)
- 방식 A: Three.js(웹 3D) in HyperFrames, 블록 장난감(로우폴리) 스타일
- 음성: ko-KR-HyunsuMultilingualNeural (2번)
- 대본: 이전 쇼츠와 동일

## 방식 (검토한 안)
- A. Three.js — **선택**. 렌더 10~20분, 수정 쉬움, 조명·그림자 단순.
- B. Blender(bpy) — 조명·질감 우수, 렌더 1~3시간, 은행 세트 직접 제작 필요.

## 화면 (Claude 판단, 사용자에게 제안한 대로)
- 세트: 땅을 자른 단면 위에 앞벽이 없는 2층 은행. 1층 창구+직원, 2층 사무실 책상, 지하 금고(돈다발). 지하 파이프가 오른쪽 작은 집까지 이어짐.
- 장면: 강도(검은 옷, 비니)가 문으로 들어가 권총으로 위협 → X 표시 → 지하 금고로 카메라 다이브 → 같은 인물이 정장 차림으로 시험·입사·2층에서 일하는 척 → 계약서 서명 → 돈다발이 파이프로 집까지 자동 이동(매달) → 리스크 0 → 어두워지며 "우리는..." → 밝아지며 "월급".
- 자막: 화면 중앙, 흰 글씨+검은 외곽선, 키워드만.
- 소리: 이전 합성 효과음 방식 재사용, 장면 동작에 맞춤. -14 LUFS 근처.
- 규격: 1080×1920, 30fps, 약 41.5초.
